# Temperature Controller Delta Pack

Use this pack only when a project has already been scaffolded and partially implemented from the earlier starter pack.

Do not overwrite the existing repository with the full v3 starter pack. Instead:

1. Copy `docs/12_TEMPERATURE_CONTROLLER_CONTRACT.md` into the existing repo.
2. Copy `prompts/05_PHASE3_TEMPERATURE_CONTROLLER_PROMPT.md` into the existing repo.
3. Copy `docs/13_EXISTING_PROJECT_TEMPERATURE_INTEGRATION_GUIDE.md` into the existing repo.
4. Copy `prompts/06_INTEGRATE_TEMPERATURE_CONTROLLER_IN_EXISTING_PROJECT.md` into the existing repo.
5. Merge the YAML snippets from `config_snippets/` into the matching profile files.
6. Ask Codex to follow `prompts/06_INTEGRATE_TEMPERATURE_CONTROLLER_IN_EXISTING_PROJECT.md`.

This delta keeps the existing project code and adds real temperature-controller support before the Hik MVS camera adapter stage.
