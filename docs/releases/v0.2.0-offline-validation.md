# v0.2.0-offline-validation

## Summary

This release brings Offline Real-Capture Validation into the main project line. It supports validating real captured `.npy` frame folders before starting Hik MVS live-camera adapter work.

## Highlights

- Merged offline real-capture validation into `main`.
- Added lazy `.npy` offline frame streaming with natural filename ordering.
- Added bounded camera frame caching for real offline frame sequences.
- Added offline validation CLI with JSON/YAML config support.
- Added dataset manifest, per-frame CSV/JSONL samples, summary JSON, curves, status histogram, A/B jump report, and optional debug overlays.
- Added GUI source selection for `dev_mock` and `dev_offline`.
- Added unified JSON/YAML config loading for profiles, detector recipes, and offline validation configs.
- Added committed ROI/config templates under `configs/validation/`.
- Updated README to describe the current working scope instead of the early scaffold state.
- Bumped backend/frontend/root project versions to `0.2.0`.

## Safety Notes

- Hik MVS adapter is still not implemented.
- OpenCV is still not introduced.
- Detector public surface remains limited to `BalloonEnvelopeDetector` and `WireStripDetector`.
- `wire_strip` remains contour-contact based, not physical endpoint based.
- Real `.npy` frame data and validation outputs remain ignored and must not be committed.

## Validation

- `python -m pytest`
- `python -m ruff check backend/src backend/tests`
- `python -m ruff format --check backend/src backend/tests`
- `npm --prefix frontend run test`
- `npm --prefix frontend run lint`
- `npm --prefix frontend run build`
